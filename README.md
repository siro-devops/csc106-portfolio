# CSC 106 Term Project: Responsive Student Portfolio

A multi-page responsive portfolio and academic management website built with HTML, CSS, and JavaScript.

## Pages
- **Home** — student intro and biography
- **About Me** — education (table), skills (lists), career goals, audio
- **Projects** — three project cards
- **Academic Planner** — interactive task manager (add / complete / delete)
- **Contact** — form with JavaScript validation

## Technologies
- HTML5 (semantic elements, forms, tables, multimedia)
- CSS3 (Flexbox, Grid, responsive media queries, animations)
- JavaScript (event handling, DOM manipulation, form validation)
